# 01: Grundgerüst und GitHub-Pages-Deployment

**What to build:** Vite + TypeScript + Preact PWA mit Startbildschirm „Junior Skat“, Manifest, Service Worker und GitHub Action, die bei Push auf `main` nach GitHub Pages deployt.

**Blocked by:** None (can start immediately)

**Acceptance:** Seite ist unter der Pages-URL erreichbar und installierbar; `npm test` und `npm run build` laufen in CI.
