# Glossar – Junior Skat

| Begriff | Bedeutung |
|---|---|
| **Offiziersskat** | Skat-Variante für 2 Spieler mit offen und verdeckt ausliegenden Karten. |
| **Stapel** | Einer von 8 Kartenplätzen eines Spielers: unten eine verdeckte, oben eine offene Karte. |
| **Vorhand** | Der Spieler, der nicht gegeben hat. Sagt Trumpf an und spielt zum ersten Stich aus. |
| **Trumpf** | Farbe (plus Buben), die alle anderen Farben sticht. |
| **Farbspiel** | Spielart: 4 Buben + gewählte Farbe sind Trumpf. |
| **Grand** | Spielart: nur die 4 Buben sind Trumpf. |
| **Bedienen** | Die ausgespielte Farbe zulegen (Buben zählen zum Trumpf). Pflicht, wenn möglich. |
| **Stich** | Je eine Karte beider Spieler; die stärkere gewinnt beide. |
| **Augen** | Kartenwerte: Ass 11, Zehn 10, König 4, Dame 3, Bube 2, sonst 0. Summe 120. |
| **Spiel** | 16 Stiche; Sieger hat mehr als 60 Augen. |
| **Schneider** | Verlierer hat höchstens 30 Augen (nur Feier + Sticker, keine Wertung). |
| **Partie** | Folge von Spielen, bis einer 3 **Pokale** hat. |
| **Pokal** | Belohnung für ein gewonnenes Spiel. |
| **Lektion** | Tutorial-Einheit aus „Schau zu“ und „Jetzt du“, bis zu 3 **Sterne**. |
| **Sticker** | Erfolg für besondere Leistungen, gesammelt im Album. |
| **Gegner-Leiter** | Fuchs (leicht) → Eule (mittel) → Bär (stark); nächster Gegner nach Partie-Sieg. |
